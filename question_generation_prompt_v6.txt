QUESTION GENERATION PROMPT v6 - TWO SETS FROM ONE LECTURE

One run produces TWO question files for ONE lecture:

  SET A - 30 first-order recall items, in lecture order, high-yield only. A fast
          drill: no vignette, short stems, short options, short explanations.
          About 15-20 seconds per item, under 12 minutes for the set.
  SET B - 15 second/third-order board-style items on the SAME lecture content,
          written to NBME conventions. About 30-35 seconds per item.

Two files, two scores. Set A rules and Set B rules are stated separately. Never
apply one set's rule to the other; where they disagree, the disagreement is
deliberate. The user names the lecture and its id (for example CV55); XXX below
means that id, and the files are Test_XXX_Recall.js and Test_XXX_Boards.js.

Run scripts/check_question_set.py on both files before registering them. It
re-verifies every number in this prompt.


**INPUTS**
- Upload the lecture PDF itself, not extracted text: the repo's extractor drops
  bold and font information.
- Paste the raw .srt transcript with timestamps: the repo's cleaners strip them,
  and timestamps are what make "how long did the lecturer spend here" visible.
- If only extracted text or a timestamp-free transcript is available, say so in
  Part 1 and note which signals were unavailable.
- Transcripts are machine-generated and mis-transcribe the exact terms items hinge
  on ("bore shift" for Bohr shift). The slide spelling always wins.


**WHEN RULES CONFLICT**
Priority: (1) scope; (2) accuracy and one best answer; (3) the high-yield gate;
(4) every other rule; (5) counts and quotas. Miss a quota rather than leave scope,
and report every shortfall in Part 1. Answer balance is never waived.


**SCOPE (both sets)**
- INTERSECTION RULE: test only concepts that are on a slide AND explained in the
  transcript. A slide-only detail the lecturer never explains is not testable; a
  transcript-only point is testable only if it is a core concept of the lecture.
- THE LECTURE DECIDES THE ANSWER. The testing point, the key, and the reason each
  distractor is worse all come from this lecture. Outside knowledge may supply only
  scenery in a Set B vignette (typical history, vital sign and lab formats, generic
  drug names) and connecting sentences in explanations. It may never be the fact
  that separates the key from a distractor.
- NO FUTURE CONCEPTS. Nothing from later courses or outside reading. If the lecture
  is vague, test the point at the depth the lecture teaches it, or skip it.
- Do not key a simplified, absolute or apparently outdated lecture statement. Test
  the underlying principle or skip it, and report it in Part 1.
- Generate nothing from a slide marked "not tested", "beyond the scope",
  "optional" or "for your interest", or from a slide the lecturer verbally
  de-scopes. List every skipped page in Part 1.


**HIGH-YIELD GATE (governs Set A selection)**
A point is testable only if it passes the intersection rule AND carries at least
one emphasis signal:

  S1 OBJECTIVE     named on the learning-objectives slide (usually page 2)
  S2 SUMMARY       restated on a summary, "key points" or take-home slide
  S3 DECK QUESTION it is what the deck's own practice question tests
  S4 BOLD          bold on the slide, if the deck passes the bold check below
  S5 VERBAL        "really important", "remember this", "you need to know",
                   "on the boards", "high yield"
  S6 DWELL         the lecturer spends about 1.5x the deck's average time per
                   content slide on it
  S7 REPEATED      the same specific claim is restated at two separated points

- Prefer points carrying two or more signals, ideally one slide signal plus one
  transcript signal. S1, S2 and S5 firing on a single announced sentence the
  lecturer never developed counts as one signal, not three.
- BOLD CHECK: if more than roughly 40 percent of the deck's body text is bold, bold
  is the body style; say so in Part 1 and drop S4. Decks in this corpus run from
  2 to 95 percent. Font size and color are theme, never emphasis.
- NEGATION GUARD: read the two sentences around any flag. "That's not particularly
  high yield" and "we don't cover this, it's just in the USMLE" are exclusions. A
  board mention is often de-scoping.
- Never require the literal phrase "high yield"; it is spoken in about one lecture
  in seven.
- Do not copy the deck's own practice question into Set A. Mine its concept, cite
  the underlying content slide, and write a fresh item. It may seed a Set B item.


**COVERAGE IN ORDER (Set A)**
1. Build a slide inventory first: mark each page FRONT (title, objectives), CONTENT,
   BACK (references, feedback), QUESTION (the deck's own practice item), or SKIPPED
   (no extractable text, or de-scoped).
2. Set A size = min(30, 2 x content slides). If the cap bites, write fewer than 30
   and say so. Forcing 30 items out of a thin deck is what produces trivia.
3. Walk the CONTENT slides from lowest page to highest, taking zero, one or at most
   two items per slide. Never go back.
4. pdfPage must be non-decreasing from item 1 to the last. Equal is fine;
   decreasing is a bug and the checker rejects the file.
5. No run of more than 3 CONTENT slides without an item, and the first and last
   CONTENT pages each carry at least one item.
6. The deck is the ordering authority, not the transcript. A point introduced on
   slide 8 and revisited near slide 17 is an S7 signal for the slide-8 item; it
   does not license a second item at page 17.
7. If an objective has no item anywhere in Set A, say so in Part 1 with the reason.


====================================================================
SET A - 30 FIRST-ORDER RECALL ITEMS
====================================================================

**ITEM FORM**
1. Recall, not application: one fact, one question, no inference chain. This
   deliberately overrides the Set B item standard.
2. No patient vignette: no age, no gender, no vital signs, no labs, no case. A bare
   clinical noun is allowed only when it IS the lecture content.
3. Default shape is the declarative subject with a short interrogative tail:
   "Intrinsic factor is secreted by which of the following cell types?" Reserve
   "Which of the following..." openings for genuine list discrimination.
4. Standalone: never refer to another item. Review modes shuffle items from many
   tests together.
5. Cover-the-options: a prepared student who reads the stem with the options hidden
   can state the answer.
6. Do not repeat a distinctive stem word or its root in the key unless every option
   uses it.
7. No classroom or source framing: no students, instructors or lecturers in the
   stem, and no "according to the lecture".

**WORD BUDGET (hard caps; the checker counts words)**
  stem                  at most 25 words, target 15
  each option           at most 8 words, target 6
  correct explanation   2 sentences, at most 45 words
  each incorrect expl.  at most 22 words INCLUDING the pivot sentence
  clinicalPearl         one sentence, at most 25 words
  whole item            at most 185 words, target 165
  whole set             at most 12 minutes to answer, 27 minutes to read fully

**OPTIONS**
- Exactly 5, one category (all cells, all mechanisms, all findings), one
  grammatical form, each directly answering the stem.
- House pattern is a noun phrase with an optional brief appositive, so all five have
  the same silhouette: "Albumin, made by the liver" / "Fibrinogen, a clotting
  protein" / "Immunoglobulin G antibody".
- Write distractors in the same register as the key; the key must not be the only
  option that copies slide wording.
- No absolute terms (always, never, only, must, cannot, completely, purely) in any
  option, key included.
- No "None of the above", no "All of the above", no opposite pairs, no collectively
  exhaustive triples (increased / decreased / no change), no two options meaning
  the same thing.
- Every distractor is a real thing from this lecture or a common misconception,
  never nonsense.

**CUT THE NUMBERS**
- ZERO items require arithmetic.
- ZERO stems contain three or more numbers.
- At most 3 of 30 items are keyed on an exact number, and only on a number that is
  bold, in an objective, or repeated in the transcript, and only cast as a rule or
  threshold. Every other number is niche: none allowed.
- At most 1 item may have an all-numeric option set.
- At least 12 of 30 items are answered by a direction, relationship or variable
  (increases, shifts right, is inversely proportional to) rather than a name or
  value.
- Permanently banned: percentage-guessing options, counting-the-criteria items,
  list positions, obscure eponyms, values readable only off a graph axis, years and
  historical figures.

**EXPLANATIONS**
Correct option: start "Correct.", then two sentences of at most 45 words - the fact
and the one contrast that matters. Do not smuggle in untested material; if content
matters enough to teach, give it its own item.

Each incorrect option: start "Incorrect.", then ONE clause naming what the option
actually is, then the pivot sentence beginning "This would be the correct answer
if". In Set A the pivot names what the distractor actually is, and the "if the
question had asked about X" form is ALLOWED and preferred: in a recall drill the
useful information is the identity of the wrong option, so the pivot doubles as a
second fact at almost no reading cost. This is the opposite of the Set B rule, on
purpose.
  Example: "Incorrect. Howell-Jolly bodies are nuclear remnants normally cleared by
  the spleen. This would be the correct answer if the question had asked about
  hyposplenism."

**ANSWER BALANCE**
- Position: exactly 6 keys per letter A-E. No letter keyed more than twice in a row,
  and no repeating cycle such as A, B, C, D, E, A, B, C.
- Length is the character count of the option text. The key is "longest" when it has
  more characters than every distractor and "shortest" when it has fewer than every
  distractor; ties count as neither. Across the 30 items the key must be longest in
  4-8 and shortest in 4-8. A key that is never longest is itself a tell.
- Method: write all five options to fit the form rules, then count. If a count falls
  outside 4-8, rephrase any option within the form rules; never pad or clip with
  filler. After rephrasing, recheck that no distractor has become defensible and
  that meaning did not drift.

**CATEGORY**
6-10 distinct category strings across the 30 items, reused across items from the
same slide run, format "Topic: Subtopic". The Pearlbook groups by exact string, so
30 unique categories renders 30 one-item groups.


====================================================================
SET B - 15 BOARD-STYLE ITEMS
====================================================================

**SCOPE LOCK (read before the NBME rules).** A Set B item may test only a concept
that already appears in Set A, or that is named in an objective, on a summary slide,
or in the deck's own practice question. "Board-style" describes the FORM of the
item, never the source of its content. Set B adds difficulty of REASONING, not new
facts. Every Set B row in Part 1 names the Set A item whose concept it escalates.

**ITEM STANDARD**
1. Application, not recall: every stem requires at least one inference, from
   findings to an unstated diagnosis or physiologic state to the asked task.
2. Cover-the-options: answerable from the stem and lead-in with options hidden.
3. Patient-centered: open with the patient. A data-only scenario (a tracing, a
   pressure-volume loop, an isolated preparation) is allowed only when interpreting
   that data is the testing point, may omit age and gender, and is capped at 2 of 15.
4. No classroom or source framing, and no "according to the lecture".
5. Standalone: never "the same patient" or "described earlier".
6. Hide what is asked: name what the patient has or was given when that is context,
   but never name the state the student must infer, and never label a finding with
   the interpretation the student is supposed to make.
7. Distractors fall to reasoning, not word matching: each is worse because of stem
   findings, which its explanation cites. No stem sentence that exists only to negate
   one option; no option that restates the opposite of a stated finding.
8. Accuracy: numbers and findings must be internally consistent and plausible
   (EDV = ESV + SV; MAP computed correctly; no therapy the vignette's own data
   contraindicate). If the key is not clearly best and every distractor clearly
   worse, rewrite the item.

**MECHANISM-FIRST VIGNETTES**
For pharmacology, pathology, microbiology, biochemistry and immunology lectures,
describe the mechanism, adverse effect, histologic finding or downstream
consequence WITHOUT naming the drug, disease, organism or enzyme being tested.
- Pharmacology: present the patient's effect; ask for the drug class, the mechanism
  of that effect, or the next step. Weak: "A patient on lisinopril develops a dry
  cough. What causes it?" Strong: "A 58-year-old man started a new antihypertensive
  3 weeks ago and now has a persistent nonproductive cough. Which of the following
  is the most likely mechanism of his cough?"
- Pathology: findings or course -> pathogenesis, complication, consequence.
- Microbiology: organism features or toxin effect -> virulence mechanism, toxin
  target, treatment rationale.
- Biochemistry: consequences of an enzyme block -> affected step or consequence.
- Immunology: pattern of dysfunction -> broken mechanism, cell or molecule.
- Exception: if the lecture's main point IS the name or classification, naming is
  acceptable.

**VIGNETTE FORMAT**
- Order (omit what is not needed): age and gender; site of care; complaint and
  duration; history; examination, including structural findings where the lecture
  teaches them; diagnostic studies; treatment and course.
- Race, ethnicity, occupation and travel only when clinically relevant, never as
  the clue.
- Vital signs in one sentence, in this order: "Temperature is 37.2 C (99.0 F), pulse
  is 112/min, respirations are 24/min, and blood pressure is 96/60 mm Hg." Add
  "Pulse oximetry on room air shows an oxygen saturation of 91%." when oxygenation
  matters. Write "Vital signs are within normal limits." only when all are normal
  and irrelevant.
- Labs in sentences, conventional US units, never labeled high or low. Give "(N=...)"
  for any analyte outside a basic metabolic panel, CBC or ABG. Ions: Na+, K+, Cl-,
  HCO3-. ABG: "Arterial blood gas analysis on room air shows a pH of 7.31, PCO2 of
  58 mm Hg, and PO2 of 62 mm Hg."
- The app shows no images or audio: describe raw findings in words ("ST-segment
  elevation in leads II, III, and aVF"), not the interpretation, when inferring it
  is part of the task.
- Generic drug names. Patients give a truthful history.

**LEAD-IN**
- One closed question about this patient, ending in "?", usually with a superlative.
- Forbidden: "Which statement is correct / most accurate / best describes...?";
  "Which of the following is the best answer?"; two questions in one; "both X and
  Y"; EXCEPT / NOT / LEAST; incomplete-sentence stems ending in ":".
- Vary the task: at most 7 of 15 lead-ins ask for a mechanism or cause. Fill the
  rest with tasks the lecture teaches - expected finding or lab pattern, predicted
  measurement, complication, next step or pharmacotherapy, adverse effect, and
  diagnosis (only when it must be inferred from several findings). Use osteopathic
  lead-ins only when the lecture teaches them. A pure physiology lecture may use
  expected-finding and predicted-measurement items instead; report the shortfall.

**WORD BUDGET (hard caps)**
  stem                  at most 65 words, target 50
  each option           at most 12 words, target 9
  correct explanation   3-4 sentences, at most 60 words
  each incorrect expl.  at most 35 words INCLUDING the pivot sentence
  clinicalPearl         1-2 sentences, at most 30 words
  whole item            at most 330 words, target 300
  whole set             at most 9 minutes to answer, 25 minutes to read fully

**OPTIONS**
- Exactly 5, one category and one grammatical form, each directly answering the
  lead-in.
- Short parallel noun phrases of 1-6 words, never more than 12; capitalized; no final
  period. One element per option: no "so", "since", "because", "which" or "leading
  to" clauses; no semicolons, parentheses or teaching notes. Move words shared by all
  options into the lead-in. In a multi-step item the option names only the link the
  lead-in asks for.
- Sets of findings (ABG, electrolyte, hemodynamic patterns): every option lists the
  same variables in the same order and format, comma separated, e.g. "pH 7.31, PCO2
  58 mm Hg, HCO3- 29 mEq/L". The word limit does not apply to these.
- Numeric options: one format, same units, ascending order.
- No absolute terms. No "None of the above" or "All of the above"; use a specific
  option such as "No pharmacotherapy is indicated at this time".
- No collectively exhaustive subsets, no opposite pairs, no two options meaning the
  same thing.
- No convergence: the key must not be the option sharing the most words or drug
  classes with the others.
- Each distractor is a common misconception or right for a similar patient; that
  other patient belongs in the explanation, never in the option text.
- If the vignette gives a classic buzzword, ask one step beyond it.
- Include one strongest competitor that experts would rank second, separated from the
  key by integrating findings. Fair, never tricky.

**CUT THE NUMBERS**
- At most 1 of 15 items requires arithmetic.
- At most 3 of 15 stems contain three or more numbers.
- At most 1 of 15 items is keyed on an exact number or percentage.
- At least 6 of 15 items are answered by a direction of change.
- Set A's permanently banned list applies here unchanged.

**EXPLANATIONS**
Correct option: start "Correct.", then 3-4 sentences of at most 60 words - the
testing point, the chain from this vignette's findings to the inference to the
answer, and why the strongest competitor is worse, named by its content rather than
as "the strongest competitor".

Each incorrect option: start "Incorrect.", then one or two sentences on why it is
wrong FOR THIS PATIENT citing the findings that make it worse than the key, then a
sentence beginning "This would be the correct answer if" that names a REAL CLINICAL
SETTING or data pattern in which this option answers this same lead-in. In Set B the
"if the question had asked..." form is FORBIDDEN, as are a change to what is being
asked, a counterfactual definition ("if velocity were defined as...") and a
counterfactual identity ("if sildenafil were a cyclase inhibitor"). Set A allows that
form because a recall drill has no patient to vary; a Set B item does, so its pivot
must vary the patient.
  Example: "Incorrect. Protein A binds the Fc portion of IgG and impairs
  opsonization, but it is made by Staphylococcus aureus, which appears as
  gram-positive cocci in clusters rather than in pairs. This would be the correct
  answer if the sputum Gram stain had shown gram-positive cocci in clusters."

Explain the medicine, not the source or the item construction: no "the lecture
said", "the lecturer", "this case is constructed to", "the distractor".

**ANSWER BALANCE**
- Position: exactly 3 keys per letter A-E. No letter keyed more than twice in a row,
  and no repeating cycle.
- Length: across the 15 items the key must be longest in 2-4 and shortest in 2-4, by
  the same character-count definition Set A uses.

**CATEGORY**
4-6 distinct category strings, format "System: Topic" (for example "Cardiology:
Heart Failure"). The performance summary shows only the three weakest and three
strongest categories, so 15 categories over 15 items surfaces nothing.


====================================================================
SHARED RULES
====================================================================

**NO LEAKAGE (audit both files together before shipping)**
- No option string appears in two different items across the two files; one item's
  key must never be another item's distractor.
- No two items share three or more option strings.
- No Set B item is answerable purely by recognizing a Set A stem.

**SCHEMA (identical in both files)**
Every item carries, in this order: id, category, questionText, options (exactly 5,
each {text, explanation}), correctAnswerIndex, clinicalPearl, lectureSource,
pdfLecture, pdfPage, pdfQuote.
- id is a sequential integer from 1 in each file independently.
- correctAnswerIndex (0-4) points to the option whose explanation starts "Correct.".
- clinicalPearl starts with the literal "Key takeaway: " and states the testing point
  as one standalone, transferable rule.
- lectureSource is one constant string per file, "CV55: Lecture Title".
- pdfLecture is the PDF_MAPPING key, on every item. Never rely on the fallback that
  parses it out of the test name.
- The array must be strict JSON: double-quoted keys and strings, no trailing commas,
  no comments.
- pdfPage is the page number as a PDF viewer counts, where the concept is primarily
  taught. pdfQuote is a 2-10 word string copied verbatim from that page, long enough
  to be unique on it: prefer the slide title, otherwise a distinctive bullet. Avoid
  spans with subscripts or superscripts, which extraction splits ("CO2" becomes "CO"
  and "2"). The app never renders pdfQuote; it is the audit anchor proving the item
  came from that slide.

**TEXT RULES**
- Plain ASCII only in every field: no degree signs, Greek letters, micro signs,
  arrows, em or en dashes, curly quotes, multiplication signs, less-or-equal signs,
  superscripts or subscripts. Write "C", "beta-1", "alpha", "mcg", "->", "-",
  straight quotes, "x", "at least", "m2", "PCO2", "HCO3-".
- Never use the "<" character; the app injects text as HTML. Write "less than".

**PART 1: PLANNING** (all of it, before any JSON)

1. PDF mapping check - the four mandatory lines below.
2. Inputs - PDF or extracted text; transcript format; estimated bold density and
   whether S4 was used or dropped; any signal unavailable for this lecture.

8. Set B table - one row per item: id | the Set A item whose concept it escalates |

     SET A: items; keys per letter (6 each); key-longest (4-8); key-shortest (4-8);

     (max 2); longest stem (25 words); longest option (8); longest correct
     explanation (45); longest incorrect explanation (22); longest item (185 words);
     arithmetic items (0); stems with 3+ numbers (0); number-keyed items (max 3);
     direction-or-relationship items (min 12); distinct categories (6-10).
     SET B: items; keys per letter (3 each); key-longest (2-4); key-shortest (2-4);
     longest stem (65 words); longest option (12); longest correct explanation (60);
     longest incorrect explanation (35); longest item (330 words); mechanism-or-cause
     lead-ins (max 7); data-only scenarios (max 2); arithmetic items (max 1); stems

     every stem standalone.
10. Scope report - skipped slides and why; quotas missed because the lecture does not
    support them; simplified or outdated lecture statements and how each was handled.
